# Dra. Leandra Coelho — Harmonização Facial (Aracaju/SE)

Prévia comercial institucional desenvolvida para apresentação web em Aracaju – SE.

## Publicação no GitHub Pages
Este projeto é 100% estático e não requer etapas de build.

1. Ative em **Settings > Pages > Build and deployment**.
2. Selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.

## Atualização após aprovação
Edite apenas o arquivo `config.js` e envie as imagens autorizadas para a pasta `images/`.
